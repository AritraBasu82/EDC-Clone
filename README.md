# EDC Auditions Website Clone


A pixel-perfect frontend clone of the **Entrepreneurship Development Cell (EDC) Auditions** portal. This project replicates the landing page and UI/UX design used to recruit aspiring entrepreneurs.

---

## 🚀 Live Demo
You can view the live version of this project here:  
**https://aritrabasu82.github.io/EDC-Clone/**

---

## ✨ Features

* **Responsive UI:** Fully optimized for desktops, tablets, and mobile devices.
* **Modern Design:** Includes smooth scrolling, hover animations, and a professional glassmorphic or minimalist aesthetic.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic structure for better SEO and accessibility.
* **CSS3:** Custom styling featuring Flexbox, CSS Grid, and Media Queries for responsiveness.
* **Google Fonts:** Specialized typography for a professional look.
